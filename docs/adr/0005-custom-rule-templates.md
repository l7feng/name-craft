# ADR 0005：自定义规则模板

- 日期：2026-11-09
- 状态：已采纳

## 背景

人类要求增加自定义规则模板：把常用规则栈保存下来，换一批文件时一键套用。规则参数已经由界面与 `settings.json` 持久化，但设置只有一份，无法在不同工作流之间切换。

## 决策

1. 模板是规则栈预设，只保存 `type`、`enabled`、`params`，不保存文件夹、拖入文件列表或冲突口径。
2. 存放 `%LOCALAPPDATA%/namecraft/templates.json`（`NAMECRAFT_HOME` 可覆盖），与设置、日志同目录；结构为 `{"version": 1, "templates": [...]}`。
3. 同名保存视为覆盖并把模板置顶；也可按 id 覆盖。名称去首尾空白、合并连续空白，最长 40 字符；单模板最多 50 条规则、最多 100 个模板。
4. 保存前经 `bridge.to_rules` 校验规则类型与结构；参数错误留给套用后的预览提示，避免模板因临时输入不完整而无法保存。
5. 套用会替换当前规则栈，界面先确认；文件列表、文件夹、冲突口径保持不变。
6. 不预置内置模板，避免把版本特定的分类或参数固化成用户数据。

## 结果

- 模板随本机用户数据保存，不进入版本库，也不跨机自动同步；需要迁移时复制 JSON 即可。
- 读取容忍损坏文件与单条坏记录，不会因一个坏模板阻断启动。
- 写入走临时文件 + `os.replace`，避免半截文件。
